# **App Name**: Study Buddy AI

## Core Features:

- AI Tutoring: Personalized learning assistance using Google AI to provide explanations, examples, and practice questions.
- Homework Help: Assists students with homework by providing guidance, hints, and explanations using a tool to extract only relevant info.
- Adaptive Learning: Adapts to the student's learning style and pace by adjusting the difficulty and content of the material.
- Progress Tracking: Tracks the student's progress and provides insights into their strengths and weaknesses.
- User Profile: Allows students to create profiles and set learning goals.
- Content Library: Offers a curated library of educational resources, including articles, videos, and interactive simulations.

## Style Guidelines:

- Primary color: HSL 220, 75%, 50% (Hex: #3D84FF) to convey trustworthiness and intelligence.
- Background color: HSL 220, 15%, 95% (Hex: #F0F4FF) for a clean and non-distracting learning environment.
- Accent color: HSL 190, 70%, 40% (Hex: #33A6B8) for interactive elements and calls to action.
- Headline font: 'Space Grotesk', sans-serif for a modern, tech-forward aesthetic; body font: 'Inter', sans-serif.
- Use clean, modern icons that are easy to understand and visually appealing.
- Maintain a clean, intuitive layout with ample whitespace to reduce cognitive load.
- Incorporate subtle animations to provide feedback and guide the user through the learning process.
